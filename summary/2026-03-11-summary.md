## 🎯 核心知识点总结

### 质量保障体系
- 预防层 + 发现层 + 响应层架构
- 错误优先级评分 = 基础分 + 影响分 + 趋势分
- 告警分级（P0/P1/P2/P3）+ 升级机制
- 错误指纹生成（去重算法）
- 采样策略（新错误 100%、已知错误采样）

### CSS 渲染机制
- 渲染管道（DOM → CSSOM → Render Tree → Layout → Paint → Composite）
- 回流 vs 重绘 vs 合成（性能消耗：Layout >>> Paint > Composite）
- BFC 原理（7 种触发条件，解决 3 个布局问题）
- 层叠上下文（9 种创建条件，z-index 工作机制）
- CSS 性能优化（transform、will-change、GPU 加速）

### React Fiber 与 Hooks
- Fiber 数据结构（链表结构）
- 双缓存机制（Current/WIP 树）
- 调度流程（Render 可中断 → Commit 不可中断）
- Hooks 链表实现（useState、useEffect）
- 闭包陷阱根因（捕获创建时的值）

## 💡 关键收获

### 1. 质量保障体系设计哲学
> "预防是理想，发现是底线，响应是关键"

对于 10 人团队，资源有限时：
- 优先建设异常监控（ROI 最高）
- 告警分级是避免告警疲劳的关键
- 错误优先级需要综合评估业务影响

### 2. CSS 性能优化核心
> "transform 代替 top/left，Composite 代替 Layout"

- 动画使用 transform/opacity
- 使用 will-change 提前优化（不滥用）
- 避免强制同步布局（读写交替）

### 3. React 设计思想
> "可中断渲染 + 批量更新 = 高性能 UI"

- Fiber 链表支持增量渲染
- 双缓存实现无副作用渲染
- Hooks 链表依赖顺序索引
